# СФ МЭИ — автоматическая сводка общего конкурса

Проект автоматически:

1. открывает конкурсные списки МЭИ через Playwright;
2. собирает данные Смоленского филиала по очному бакалавриату;
3. считает основной конкурс, переполнение и минимальный балл;
4. формирует веб-страницу и Excel;
5. публикует результат в GitHub Pages.

## Важно

- Репозиторий должен быть **публичным**, если используется бесплатный GitHub Free.
- На странице публикуются только агрегированные данные, без УИП.
- Кнопки ручного обновления на самой странице нет. Ручной запуск выполняется на вкладке **Actions**.
- Если сбор завершится ошибкой, развёртывание не произойдёт и прежняя успешная страница останется доступной.
- Скрипт пока сохраняет исходное правило поиска ссылки с текстом «7 августа».

Подробные действия описаны в файле `ИНСТРУКЦИЯ_ПО_ШАГАМ.md`.
