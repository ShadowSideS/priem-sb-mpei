# Пошаговая установка на GitHub Pages

## 1. Создайте аккаунт GitHub

Откройте GitHub и зарегистрируйтесь. Подтвердите электронную почту.

## 2. Создайте новый репозиторий

1. Нажмите значок `+` в правом верхнем углу.
2. Выберите `New repository`.
3. В поле имени укажите, например: `sf-mei-monitor`.
4. Выберите `Public`.
5. Не добавляйте README, `.gitignore` и лицензию: они уже есть в комплекте.
6. Нажмите `Create repository`.

## 3. Загрузите файлы

1. На странице пустого репозитория нажмите `uploading an existing file`.
2. Распакуйте этот архив на компьютере.
3. Перетащите в окно GitHub **всё содержимое папки**, включая папку `.github`.
4. Внизу нажмите `Commit changes`.

Важно: в Проводнике Windows папка `.github` может отображаться нормально, но убедитесь, что она действительно попала в репозиторий.

## 4. Включите GitHub Pages

1. Откройте `Settings` репозитория.
2. Слева откройте `Pages`.
3. В блоке `Build and deployment` выберите источник `GitHub Actions`.

## 5. Запустите первый сбор

1. Откройте вкладку `Actions`.
2. Слева выберите workflow `Обновить сводку МЭИ`.
3. Нажмите `Run workflow`.
4. Выберите ветку `main` и подтвердите запуск.
5. Подождите завершения. Зелёная галочка означает успех.

Первый запуск может идти несколько минут, поскольку GitHub устанавливает Chromium.

## 6. Откройте готовую страницу

После успешного запуска:

1. Откройте `Settings` → `Pages`.
2. Там появится адрес вида:
   `https://ВАШ_ЛОГИН.github.io/sf-mei-monitor/`

Это постоянная ссылка для просмотра сводки.

## 7. Автоматическое обновление

Workflow запланирован примерно каждые 15 минут. GitHub может запускать задачи с небольшой задержкой. Также ручной запуск всегда доступен во вкладке `Actions`.

## Ограничения бесплатного варианта

- Страница и исходный код публичны.
- Пароль поставить нельзя средствами обычного GitHub Pages.
- Автоматический запуск может задерживаться.
- В публичном репозитории расписание может автоматически отключиться после длительного отсутствия активности. Тогда достаточно открыть `Actions` и снова включить workflow либо сделать небольшой commit.
